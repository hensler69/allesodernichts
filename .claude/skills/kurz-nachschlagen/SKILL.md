# Kurz nachschlagen

Eine kurze, aber treffende Antwort. Nur Websuche benutzen, sonst nichts.

## Vorgehen
Kurze Suche nach Primärquellen. 

Hochwertige Quellen filtern: Gesetz oder Behörde vor Hersteller vor Fachpresse. Blogs nur, wenn nichts Besseres existiert. Quellen im Original öffnen.

## Form
Behalte exakt dieses Format in deiner Antwort bei.

```
**[Die Antwort / Das Ergebnis in einer Zeile, max 20 Wörter]**
━━━━━━━━━━━━━━━━━━━━━━━━━
Fakten [Genau 4 Stück, je max. 20 Wörter]:

- [Ein Satz mit einem Fakt] ([Herausgeber, Monat Jahr](Link))
- [Ein Satz mit einem Fakt] ([Herausgeber, Monat Jahr](Link))
- [Ein Satz mit einem Fakt] ([Herausgeber, Monat Jahr](Link))
- [Ein Satz mit einem Fakt] ([Herausgeber, Monat Jahr](Link))

Fazit für dich:
[Die Essenz auf einen Satz heruntergebrochen]

[Keine weiteren Ausgaben, auch keine Quellen, Erklärungen, etc.]
```
