    Mit diesen Themen anfragen

    Angebot

    Drei Bereiche. Ein Ansprechpartner.

    Tippen Sie eine Kachel an, dann sehen Sie, worum es konkret geht.

    Sparten

    Alle Sparten auf einen Blick.

    Berühren Sie das Logo. Dann wachsen die Sparten heraus, und unter jeder Sparte die einzelnen Versicherungen.

    Eine beispielhafte Übersicht, das Logo ist erfunden und dient nur der Anschauung. Welche Sparten für Sie passen, klären wir im Gespräch. Tippen Sie eine Versicherung an, dann merke ich sie im Formular vor.

    Ablauf

    So läuft das Erstgespräch.

      Sie schreiben mir

    2. Schritt 2

      Wir sprechen in Ruhe

      Ich höre zu, stelle Fragen und sehe mir an, was Sie schon haben.

    3. Schritt 3

      Sie bekommen eine klare Empfehlung
